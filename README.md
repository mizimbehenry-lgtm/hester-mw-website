# Hester Mw — Official Website

A lightweight, responsive artist website built with plain HTML, CSS and JavaScript.

## Project structure

```text
hester-mw-website/
├── index.html
├── .nojekyll
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        └── favicon.svg
```

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `hester-mw-website`.
2. Upload all files while keeping the folder structure.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save. GitHub will generate the public Pages address.

## Before publishing

Replace:
- `YOUR-EMAIL@example.com`
- Spotify URL
- YouTube URL
- Facebook URL
- TikTok URL
- The placeholder video button
- Release streaming links

You can also replace the CSS-generated cover artwork with official 3000×3000 release covers later.
